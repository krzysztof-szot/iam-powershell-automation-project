# Evidence guide

Each daily folder contains the planned screenshot names and the observation each image should demonstrate. Add screenshots after the corresponding lab test and update its result record.

Redact credentials, tokens, real identities, tenant identifiers and unrelated details before adding files to Git. Keep raw exports and console logs in `local-output/`.

For Windows access checks, capture the test identity and exact share being tested. After a group change, use a fresh session to verify effective access. For Entra, capture audit evidence on the day of the exercise.
